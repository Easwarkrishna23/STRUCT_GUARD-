# Cora Dataset — Gated Attack & Defense Results

**Status:** stale weak-result table invalidated.

The previous Cora table showed structural attacks with only 0.2–6.5 percentage-point damage and defenses below baseline. Those rows are no longer accepted by the current framework.

Current acceptance gates in `utils/config.py`:

| Gate | Requirement |
| --- | --- |
| Attack degradation | `baseline_acc - attacked_acc >= 0.50 * baseline_acc` |
| Defense recovery | `defended_acc >= baseline_acc` |
| Injected-edge pruning | `injected_edge_prune_rate >= 90%` |
| Cache validity | `phase45_cache.json` must match the current config signature |

For the previously reported Cora baseline of `0.8010`, a final accepted attack row must satisfy:

```text
attacked_acc <= 0.4005
defended_acc >= 0.8010
injected_edge_prune_rate >= 0.9000
```

Fresh results are generated by:

```bash
python run_full_pipeline.py
```

The pipeline now hard-fails before writing accepted tables if any attack, defense, or injected-edge pruning row violates the gate. This file intentionally does not preserve the old weak numbers.
