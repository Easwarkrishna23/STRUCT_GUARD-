**Status:** stale weak-result table invalidated.

Current acceptance gates in `utils/config.py`:

| Gate | Requirement |
| --- | --- |
| Attack degradation | `baseline_acc - attacked_acc >= 0.50 * baseline_acc` |
| Defense recovery | `defended_acc >= baseline_acc` |
| Injected-edge pruning | `injected_edge_prune_rate >= 90%` |
| Temporal ontology | `SuspiciousNode` detection is evaluated against the previous snapshot |

```text
attacked_acc <= 0.4375
defended_acc >= 0.8750
injected_edge_prune_rate >= 0.9000
```

The current pipeline applies the same metric surface to Elliptic as Cora: ASR, embedding drift, neighborhood entropy, homophily drop, Bose-Einstein fitness, assortativity coefficient, clean-label recovery, and injected-edge pruning.

Fresh results are generated by:

```bash
python run_full_pipeline.py
```

The pipeline now hard-fails before writing accepted tables if any final Elliptic attack, recovery, or pruning row violates the gate. This file intentionally does not preserve the old weak numbers.
